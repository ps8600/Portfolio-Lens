
# Portfolio Lens Web App

A Swiss Pension Funds portfolio analysis tool built with Streamlit.

## Features

- Interactive portfolio allocation controls
- Real-time performance comparison
- Four key portfolio parameters:
  - Equities/Bonds Ratio
  - Home Bias Equities
  - Yield Curve CHF
  - FX Hedging

## Run locally

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Start the app

```bash
streamlit run app.py
```

3. Open in your browser (works with Chrome, Edge, Firefox, Safari, etc.)

The app is optimized for Microsoft Edge on desktop.

## Deploy publicly

Recommended hosting:
- Streamlit Cloud
- Render
- Railway
